# KampusMarket Product Context

Register: product

KampusMarket is a React Native and Expo mobile application for the UAS Praktikum Pemrograman Mobile brief. It serves university students who want a quick, trustworthy way to browse second-hand campus goods from a marketplace catalog.

The assessment audience is a programming practicum reviewer. The app needs to make the required mobile concepts visible without feeling like a checklist: protected login, tab navigation, reusable components, FlatList rendering, search and category filtering, form validation, screen-to-screen navigation, and network state handling for DummyJSON.

Design principles:

- Keep the interface task-first, compact, and readable on phone screens.
- Use a restrained product palette with warm neutral surfaces, campus green for primary actions, amber for commerce emphasis, and rose only for destructive or error states.
- Make loading, empty, and error states explicit so the app never feels frozen.
- Favor native mobile patterns over decorative web-style landing pages.
- Use real product imagery from DummyJSON as the main visual asset.
